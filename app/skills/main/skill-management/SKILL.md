# 技能生命周期管理

## 概述
本技能负责管理其他技能的完整生命周期，包括安装、更新、启用、禁用和卸载。

## 操作指令

### 安装技能
1. 验证技能配置文件的完整性
2. 将技能文件复制到沙箱指定目录
3. 通过 StoreBackend 持久化技能元数据
4. 确认技能可用

### 更新技能
1. 比较当前版本与目标版本的差异
2. 增量更新变更的文件
3. 更新持久化元数据

### 禁用/启用技能
- 禁用：从沙箱移除技能文件，但保留持久化记录
- 启用：从持久化记录恢复技能文件到沙箱

### 卸载技能
1. 从沙箱移除技能文件
2. 删除 StoreBackend 中的持久化记录
3. 清理相关缓存
